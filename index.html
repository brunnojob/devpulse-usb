O FLUXO

Do seu PC para a mesa.

O computador coleta. O USB transporta.
O ESP32 transforma números em informação.

01

Coletar

O agente Python lê CPU, RAM, ocupação do volume e tráfego agregado de rede usando psutil.

python agent.py --port COM5
02

Transportar

Pacotes JSON versionados via serial. O mesmo cabo USB alimenta a placa e leva as métricas.

JSON + LF / 115200 baud
03

Acompanhar

O firmware exibe métricas e alerta após dez segundos de CPU ou RAM acima de 90%.

PC → USB → ESP32 → tela

ANTES DE GRAVAR

Confirme sua placa.

A foto não identifica a pinagem ou o controlador da tela. O firmware inclui um perfil ST7789 que precisa ser confirmado e configurado.

O agente foi testado neste ambiente; compilação e execução física do firmware ainda estão pendentes.
